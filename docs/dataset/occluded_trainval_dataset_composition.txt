The following lines of code are the reason why positive and negative presence differs:

    for emotion in emotions:
        for i in range(0, 50):
            # do matching occlusion
            if i < nof_match_occlusions:                # nof_match_occlusions is 10
                chosen_emotion = emotion
                AUs = EMOTION_AUS[chosen_emotion]
                mask_type = "positive"
            # do mismatching occlusion
            else:                                                         
                mism_emotion_index = (i - nof_match_occlusions) // (nof_images_per_occlusion_type * 2)
                chosen_emotion = spin_emotion(mism_emotion_index, emotion_to_exclude=emotion)
                AUs = EMOTION_AUS[chosen_emotion]
                if i % 2 == 0:
                    mask_type = "positive"
                else:
                    mask_type = "negative"

Basically whenever the occlusion is matching, we only do positive occlusion, while for
 mismatching occlusions we alternate between positive and negative
